# Линейная алгебра и геометрия для физиков

Методическое пособие для студентов физического факультета НГУ по курсу «Линейная алгебра и геометрия» (2 семестр) и «Геометрия и алгебра» (3 семестр). Пособие пополняется по главам.

## Две версии каждой главы

| Папка | Для чего |
|---|---|
| [`pdf/`](pdf/) | Для чтения: цветные рисунки, раскадровки анимаций с QR-кодами. |
| [`llm/`](llm/) | Для подготовки с нейросетью (Qwen, DeepSeek и др.): загрузите файл главы в чат и отправьте инструкцию из начала файла. Рисунки описаны словами, ответы к задачам скрыты до вашей попытки. |
| [`anim/`](anim/) | Анимации, на которые ведут QR-коды из PDF. |
| [`src/`](src/) | Исходники LaTeX (XeLaTeX). |

## Цветовой код рисунков

- **синий** — исходные векторы, базис;
- **красный** — образы, результат действия;
- **зелёный** — собственные и инвариантные направления;
- **оранжевый** — физические величины.
